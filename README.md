# tgo-sandesh

VSL funnel for **Sandesh Soans** (Extreme or Nothing Protocol, 90-120 day natural
physique transformation, ₹97 entry).

- Stack: Next.js 16 App Router, React 19, TypeScript, plain CSS (no Tailwind).
- Design: the SDP VSL component system (`~/.claude/system/design-system.skin.sdp-vsl.md`),
  re-themed to **volt on graphite**. Only the Part 1 token block and the two font
  families change; component anatomy, spacing, motion and the light/light-alt/dark
  band rhythm are identical to the locked skin.
- Structure: the 13-beat VSL blueprint from `~/.claude/shape/structure-library.md`,
  built by the SHAPE agent.
- Copy source of truth: `funnel-copy/01-landing-vsl.md` (verbatim from Atul, do not re-voice).

## Run it

```
npm install
npm run dev
```
